# Preview главной DomianKvartal V2

## Созданные файлы

- `index-preview.html` — отдельная копия главной с preview-разметкой.
- `assets/css/home-preview-v2.css` — изолированный premium-слой; все селекторы начинаются с `.home-preview-v2`.
- `assets/js/home-preview-v2.js` — компактная шапка, reveal через `IntersectionObserver`, stagger и лёгкий pointer-parallax.
- `PREVIEW_HOME_NOTES.md` — этот handoff.

## Что изменено только в preview

- Шапка собирается в blur-панель после прокрутки и не конфликтует с открытым drawer-меню.
- Hero стал спокойнее и цельнее; реальная карточка объекта и основные маршруты сохранены.
- Псевдопоиск заменён честным CTA «Перейти к подбору».
- Ранние действия упрощены до главного перехода к объектам и вторичного сценария собственника.
- Визуальные псевдофильтры заменены честным переходом в полный каталог.
- Кнопки, карточки, поверхности, секционный ритм и финальный CTA получили единый premium-polish.
- На узких экранах мини-карточки собраны в горизонтальную ленту; для `844×390` есть отдельная компактная композиция.
- Preview не запускает production-аналитику.

## Как открыть

Из корня `C:\Alieva\DomianKvartal`:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

URL preview: `http://127.0.0.1:8765/index-preview.html`

Оригинал для сравнения: `http://127.0.0.1:8765/index.html`

Остановить сервер после просмотра: `Ctrl+C`.

## Проверка

Локальный Chromium проверен на:

- `1440×900`
- `1080×900`
- `768×1024`
- `393×852`
- `375×812`
- `844×390`

Результат: preview CSS/JS загружаются, ошибок консоли нет, горизонтального скролла страницы нет, якорный CTA работает, мобильное меню открывается/закрывается и восстанавливает состояние шапки, compact-header работает в обе стороны, reveal завершает наблюдение (`pending=0`, все цели раскрыты), reduced-motion отключает движение и parallax. Исходный `index.html` отдельно открыт и не подключает preview CSS/JS.

Hover-правила кнопок и карточек загружены и активны только при `(hover: hover) and (pointer: fine)`; touch-режим остаётся нейтральным. Встроенный browser-driver не удерживает псевдосостояние `:hover` для визуального кадра, поэтому субъективную скорость sheen/подъёма стоит дополнительно оценить обычной мышью при ручном просмотре.

## Как полностью удалить эксперимент

Удалить только четыре файла из раздела «Созданные файлы». Других откатов или изменений существующей главной не требуется.
