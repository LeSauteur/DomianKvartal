## Сборка и проверки

В PowerShell из этой рабочей папки:

```powershell
npm ci
node _tools/build-registry.mjs
node _tools/build-object-pages.mjs
node _tools/build-seo-pages.mjs
node _tools/build-zhk-pages.mjs
py tools/generate-construction-catalog.py
node _tools/sync-public-header.mjs
node _tools/build-sitemap.mjs
node _tools/report-editorial-review.mjs
$env:PLAYWRIGHT_BASE_URL = 'http://127.0.0.1:42761'
npm run qa
```

На Linux вместо `py` использовать `python3`. Нужен Google Chrome для текущей конфигурации Playwright. Если порт занят, выбрать другой свободный порт в `PLAYWRIGHT_BASE_URL`.

`_tools/edit-catalog-copy.mjs` — одноразовая миграция от базы 1976779, а не шаг обычной сборки. Повторный запуск перезапишет последующие ручные правки редакторских блоков своими подготовленными вариантами. Для обычной сборки использовать команды выше.

