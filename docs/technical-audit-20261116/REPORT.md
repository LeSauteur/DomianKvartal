## Сборка и регрессии

- `npm run build:catalog` — реестр, карточки объектов и ЖК, локальные подборки, каталог ЖК, общий блок навигации, sitemap.
- `npm test` — в том числе неизменность исходных описаний, характеристик, конфликтующих значений, фотографий и публичных описаний относительно коммита аудита.
- `npm run test:browser` — браузерные проверки. Запросы к Web3Forms подменяются; реальные заявки не отправляются.
- `npm run seo:audit`, `node _tools/sync-public-header.mjs --check`, `node _private/validate-newbuilds-v3.js`.
- `npm run check:indexation` — повторная проверка контрольной выборки на опубликованном сайте и запись даты проверки. Она проверяет текущую опубликованную версию, а не публикует локальные изменения.

Окончательные результаты прогонов см. в `VALIDATION.md`. После проверки переходов исправлен также фокус при переходе с локальной подборки прямо к форме объекта: браузер мог переопределить фокус после DOMContentLoaded. Теперь он восстанавливается после загрузки; если пользователь уже работает с полями формы, его фокус сохраняется.

## Что требует внешних данных

Причина исключения Google для каждой из 203 карточек остаётся отдельной задачей проверки URL в GSC: дата последнего обхода, ответ на проверку опубликованного URL, выбранный Google canonical и при необходимости сведения о доступе робота. Массовое снятие canonical/noindex не выполнялось.

Уточнение цен, площадей, географии, доступности и принадлежности фотографий требует подтверждённых источников. Существующие конфликты не разрешались выбором удобного числа. Публичные описания не переписывались и не сокращались. Список `data-to-confirm.csv` содержит адресные вопросы по текущему реестру; отсутствие индивидуальной проверки относится ко всем 220 объектам.

Здесь не делается вывод о качестве отработки заявок, окупаемости сайта или связи конкретного обращения с Google. Повторный сбор исходных показателей аудита не выполнялся.
