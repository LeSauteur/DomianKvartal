# Проверка реестра владельцем

Источник сайта — data/catalog/registry.json; сборка: node _tools/build-registry.mjs.
Папка data/ исключена из публикации. output/catalog/registry.json — публичная проекция
для интерфейса; output/*/new-objects.json — производные ленты с прежним составом.

registry-to-verify.csv — UTF-8, разделитель «;». Сохраните заполненную копию под
другим именем: генератор пересобирает исходный список. Подтверждённые факты внесите
в data.json соответствующего объекта вместе с verifiedAt и verifiedBy; затем
пересоберите реестр и страницы. Для объектов только из лент сначала создайте
обычный data.json с сохранением ID и реальных данных, без догадок.

Город не определяется по названию ЖК, «Ростовская область», времени поездки или
зоне работы риэлтора. Это объясняет расхождение с исходным подсчётом:
у квартир подтверждены 6 Аксай / 38 Ростов-на-Дону, 84 требуют города
(включая 4 объекта только из лент). У домов: 86 записей, из них 78 без города;
у участков: 21 запись, 14 без города.

Цена при конфликте отсутствует во всех производных данных. Исходные значения
сохранены в price_conflict.sources и неизменяемом data/catalog/source-feeds.json.
Конфликты: object_901 (9 000 000 / 5 250 000), object_907 (5 950 000 / 5 050 000),
object_908 (6 350 000 / 5 000 000), object_910 (5 950 000 / 5 050 000).
Не исправляйте конфликт только в сгенерированной ленте: подтвердите цену и
согласуйте все источники, включая архив миграции, сохранив историю решения в git.

photo_folder_mismatch сообщает о различии ID объекта и папки фотографий.
Само различие не доказывает ошибку; владелец должен подтвердить соответствие.
До подтверждения фото не переносятся и не заменяются.

status=null означает, что актуальность не подтверждена. Это не утверждение
«объект продаётся». verifiedAt и verifiedBy также остаются null без проверки.

## Изменения после ревью PR #23

20 записей house_901–910/land_901–910 имеют status=placeholder по исходному is_placeholder=true. Они остаются в закрытом реестре для учёта, исключены из публичных данных, страниц и списка проверки. Среди реальных домов 76 записей, 68 без города; среди реальных участков 11 записей, 4 без города.

area_conflict отмечает различие общей площади в заголовке и описании, неоднозначные общие площади либо малую площадь из заголовка без подтверждения в описании. В CSV добавлены area_title, area_description, area_evidence (цитаты) и area_selected. Площади кухни, жилых комнат, балкона и лоджии не подменяют общую площадь. Явная общая площадь в описании имеет приоритет; заголовок меньше 20 м² без однозначного подтверждения не используется. При конфликте двух общих площадей значение остаётся null. Подтвердите значение в исходном тексте/данных объекта; не исправляйте только производную ленту.
