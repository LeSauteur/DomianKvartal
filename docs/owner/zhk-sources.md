# Источники ЖК и пределы проверки — 07.10.2026

Факты из задания перенесены без расширения в data/zhk/aksay.json.
provenance=owner_supplied_snapshot отличает предоставленную справку от новой
независимой проверки; independent_check хранит результат чтения источника.
verifiedAt — дата предоставленного снимка, а не подтверждение текущей доступности
квартир агентством. Сроки и цены должны проверяться при обращении.

- [Флора](https://доннефтестрой.рф/projects/flora): официальная страница доступна,
  подтверждает публикацию цены от 3 млн и ближайшую сдачу IV кв. 2027.
  Отдельную новость о сдаче 03.02.2026 инструмент не нашёл на странице проекта.
- [ЮгСпецСтрой](https://www.yugspecstroy.ru/kompleksy/): каталог доступен, но
  «Вишнёвый сад» не найден в извлечённом тексте. Нужна прямая карточка проекта.
- [Самоцветы, ЕИСЖС 40962](https://наш.дом.рф/сервисы/каталог-новостроек/объект/40962)
  и [Атмосфера, ЕИСЖС 36960](https://наш.дом.рф/сервисы/каталог-новостроек/объект/36960):
  страницы недоступны инструменту; сохранены ровно факты владельца с указанием
  конкретных домов/корпусов, без новых фактов.
- По «Новый Аксай» источника нет; страница содержит только информационный блок.
- [Придонье](https://sskuban.ru/rostov-na-donu/pridonye) и
  [Авиатор](https://su5aksay.ru/) доступны; [Столицыно](https://zhkstolitsino.ru/)
  недоступно инструменту. Для всех трёх publish=false: HTML не создавался.

После подтверждения владельцем продаж в новых ЖК:
node _tools/build-zhk-pages.mjs --only pridonye,stolitsyno,aviator

Эта команда создаст страницы и активирует publish в справочнике. Затем
пересобрать sitemap, синхронизировать шапку, обновить проверки/таблицу решений
для расширенного набора страниц и открыть отдельный PR.
